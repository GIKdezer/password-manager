# CLI Password Manager (Zero-Knowledge)

Простой и надежный менеджер паролей для терминала, написанный на Python. Проект сфокусирован на изучении криптографических примитивов и безопасном хранении данных.

## Особенности безопасности
В отличие от простых хранилищ, этот проект использует современные стандарты безопасности:
*   **Argon2id**: Современная функция извлечения ключа (KDF), устойчивая к перебору на GPU. Мастер-пароль никогда не хранится в чистом виде.
*   **AES-128 (Fernet)**: Симметричное шифрование в режиме CBC с использованием HMAC для проверки целостности данных.
*   **Zero-Knowledge**: Ваши пароли шифруются локально. Даже если файл базы данных будет украден, без мастер-пароля данные расшифровать невозможно.

## Технологии
*   **Язык**: Python 3.x
*   **Криптография**: `cryptography`, `argon2-cffi`
*   **Интерфейс**: `typer` (CLI), `rich` (стилизация консоли)
